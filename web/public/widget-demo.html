cainban embeddable widget

One <script> tag plus a <div data-cainban-widget> renders a live board-status card on any site. Each widget mounts into its own Shadow DOM, so the host page's Comic Sans and letter-spacing above never touch it.

Minimal usage

<script src="cainban-widget.js"></script>
<div data-cainban-widget data-repo="owner/repo"></div>

Live examples

All attributes

data-repo        owner/repo (required)
data-api         MCP endpoint URL (optional; defaults to <board-url>/mcp)
data-token       read-only bearer token (optional; for authed servers)
data-board-url   full board URL opened on click (optional)
data-theme       "light" | "dark" (optional; omit to follow the OS)
data-poll        refresh interval in seconds (optional; 0 disables; default 30)
data-bar         "true" | "false" mini-board bar (optional; default true)

Inject widgets after load? Call window.cainbanWidget.mount() to upgrade any new [data-cainban-widget] elements.
